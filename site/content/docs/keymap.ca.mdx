Cada acció de Parla té un nom estable. La paleta d'ordres i el mapa de tecles usen
aquests noms.

Les tecles de sota són els valors predeterminats a macOS. A Linux i Windows, usa
`ctrl` en lloc de `cmd` excepte on la taula digui una altra cosa. Un guió vol dir
que l'acció no té tecla predeterminada.

Prem `cmd-/` (`ctrl-/` a Linux i Windows), o tria Ajuda, Dreceres de teclat, per
obrir el full de dreceres. Mostra cada acció que té tecla, agrupada per àrea, i
mostra les tecles que has canviat. Escriu al seu camp de cerca per filtrar per nom
o tecles. **Edita el mapa de tecles** obre Paràmetres, Tecles.

## Canviar una drecera

Obre Paràmetres, Tecles. La pàgina enumera cada acció amb la seva drecera, el seu
context i el seu origen: **Predeterminat**, o **Tu** quan l'enllaç ve del teu
`keymap.json`.

1. Troba l'acció desplaçant-te o cercant per nom o tecles.
2. Fes clic a la seva drecera, o enfoca-la i prem Retorn o Espai.
3. Prem les tecles noves i prem Retorn, o tria **Desa**.
4. Tria **Restableix** per treure el teu enllaç i recuperar el predeterminat.

**Canviats** enumera només els teus enllaços. **Conflictes** enumera les tecles que
comparteixen dues accions on es creuen una tecla global i una de context; la de
context guanya mentre té el focus.

Una segona tecla crea una seqüència, com `cmd-k cmd-s`. Una tercera comença de nou.
Escape cancel·la, i Tab es mou als botons Desa i Cancel·la, així que cap de les
dues es pot gravar. Una tecla que escriu text necessita un modificador per a una
acció global o al compositor, els camps de text i els selectors.

Els teus enllaços viuen a `keymap.json`, un array d'objectes de context i enllaços:

```json
[
  {
    "bindings": {
      "cmd-q": null,
      "cmd-shift-q": "app::Quit"
    }
  }
]
```

`null` treu un enllaç predeterminat. Els comentaris es conserven quan Parla escriu
el fitxer. Els canvis s'apliquen a l'instant.

La paleta d'ordres (`cmd-shift-p`) enumera les accions que pots executar, amb les
seves tecles. És la forma més ràpida de trobar una acció sense recordar-ne el nom.
