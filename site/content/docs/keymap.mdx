Every action in Parla has a stable name. The command palette and the keymap use
those names.

The keys below are the macOS defaults. On Linux and Windows, use `ctrl` in place
of `cmd` except where the table says otherwise. A dash means the action has no
default key.

Press `cmd-/` (`ctrl-/` on Linux and Windows), or choose Help, Keyboard
shortcuts, to open the shortcuts sheet. It shows every action that has a key,
grouped by area, and it shows the keys you changed. Type in its search field to
filter by name or keys. **Edit keymap** opens Settings, Keymap.

## Change a shortcut

Open Settings, Keymap. The page lists every action with its shortcut, its
context and its source: **Default**, or **You** when the binding comes from your
`keymap.json`.

1. Find the action by scrolling or searching by name or keys.
2. Click its shortcut, or focus it and press Enter or Space.
3. Press the new keys and press Enter, or choose **Save**.
4. Choose **Reset** to remove your binding and bring back the default.

**Changed** lists only your bindings. **Conflicts** lists keys that two actions
share where a global key and a context key meet; the context key wins while it
has focus.

A second key makes a sequence, such as `cmd-k cmd-s`. A third starts over.
Escape cancels, and Tab moves to the Save and Cancel buttons, so neither can be
recorded. A key that types text needs a modifier for a global action or in the
composer, text fields and pickers.

Your bindings live in `keymap.json`, an array of context and binding objects:

```json
[
  {
    "bindings": {
      "cmd-q": null,
      "cmd-shift-q": "app::Quit"
    }
  }
]
```

`null` removes a default binding. Comments are kept when Parla writes the file.
Changes apply at once.

The command palette (`cmd-shift-p`) lists the actions you can run, with their
keys. It is the quickest way to find an action without remembering its name.
