Cada acción de Parla tiene un nombre estable. La paleta de comandos y el mapa de
teclas usan esos nombres.

Las teclas de abajo son los valores predeterminados en macOS. En Linux y Windows,
usa `ctrl` en lugar de `cmd` excepto donde la tabla diga otra cosa. Un guion
significa que la acción no tiene tecla predeterminada.

Pulsa `cmd-/` (`ctrl-/` en Linux y Windows), o elige Ayuda, Atajos de teclado,
para abrir la hoja de atajos. Muestra cada acción que tiene tecla, agrupada por
área, y muestra las teclas que has cambiado. Escribe en su campo de búsqueda para
filtrar por nombre o teclas. **Editar mapa de teclas** abre Ajustes, Teclas.

## Cambiar un atajo

Abre Ajustes, Teclas. La página enumera cada acción con su atajo, su contexto y su
origen: **Predeterminado**, o **Tú** cuando el enlace viene de tu `keymap.json`.

1. Encuentra la acción desplazándote o buscando por nombre o teclas.
2. Haz clic en su atajo, o enfócalo y pulsa Intro o Espacio.
3. Pulsa las teclas nuevas y pulsa Intro, o elige **Guardar**.
4. Elige **Restablecer** para quitar tu enlace y recuperar el predeterminado.

**Cambiados** enumera solo tus enlaces. **Conflictos** enumera las teclas que
comparten dos acciones donde se cruzan una tecla global y una de contexto; la de
contexto gana mientras tiene el foco.

Una segunda tecla crea una secuencia, como `cmd-k cmd-s`. Una tercera empieza de
nuevo. Escape cancela, y Tab se mueve a los botones Guardar y Cancelar, así que
ninguna de las dos se puede grabar. Una tecla que escribe texto necesita un
modificador para una acción global o en el compositor, los campos de texto y los
selectores.

Tus enlaces viven en `keymap.json`, un array de objetos de contexto y enlaces:

```json
[
  {
    "bindings": {
      "cmd-q": null,
      "cmd-shift-q": "app::Quit"
    }
  }
]
```

`null` quita un enlace predeterminado. Los comentarios se conservan cuando Parla
escribe el archivo. Los cambios se aplican al instante.

La paleta de comandos (`cmd-shift-p`) enumera las acciones que puedes ejecutar,
con sus teclas. Es la forma más rápida de encontrar una acción sin recordar su
nombre.
