# Bundled fonts

- Inter 4.1 static fonts, from the official release's `extras/ttf` folder:
  `Inter-Regular.ttf`, `Inter-Italic.ttf`, `Inter-Medium.ttf`,
  `Inter-SemiBold.ttf` and `Inter-Bold.ttf`.
- Unmodified; the SIL Open Font License 1.1 text is in `Inter-LICENSE.txt`.
  Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter).

Parla registers these at start-up so the default UI font (`Inter`) and its
design weights (400/500/600/700) render on a machine without Inter installed.
The visual test harness renders from the same bytes.
